### 🚀 Projeto em destaque

## CarHealth

Sistema de monitoramento automotivo desenvolvido em **Python e SQLite**, criado para aplicar na prática conceitos de programação, banco de dados e organização de projetos.

O sistema permite:

- Cadastrar veículos
- Listar veículos
- Excluir veículos
- Armazenar dados utilizando SQLite
- Analisar a temperatura do motor
- Verificar a tensão da bateria
- Calcular consumo médio de combustível
- Calcular o custo de combustível da viagem
- Analisar a pressão dos quatro pneus
- Comparar a pressão atual com a recomendada para cada veículo
